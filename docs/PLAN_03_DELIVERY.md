## 3. 已实现

### F1 自动收纳

- 手动完成/阶段全部完成后 `status=completed`，列表刷新；
- 默认“待完成”表不展示已完成任务；
- 已完成任务进入折叠归档；
- 完成数、完成率、计划分钟立即重算；
- 不删除任务及实际/阶段/答案证据。

### F2 视图

- 待完成（默认）：所有未完成，含逾期；
- 今天：今天日期的未完成任务；
- 全部：全部任务（含已完成）；
- 已完成：已完成归档，按完成日期分组。

### F3 已完成折叠

- `<details>` 默认折叠，摘要显示数量；
- 展开后按完成日期分组；
- 可查看阶段记录、实际时长/题量、完成来源、编辑/删除/撤销；
- 缺少 `completedAt` 的旧任务按原计划日期分组。

### F4 撤销完成

- `撤销完成` 将 `status` 恢复为 `pending`，清除 `completedAt`；
- 保留 `actualMinutes/actualQuestions/actualCorrect/actualSource/stageActuals`；
- 记录 `undoHistory` 供审计；
- 撤销后立即回到待完成列表，完成率重算；
- 不删除原始作答证据。

### F5 自动更新

完成后 `load()` 重读任务，页面无需手动刷新；导入计划、修改实际记录、切换日期、撤销均走同一刷新路径。

### F6 持久化

状态写入现有 `learningTasks`；重新打开应用后由 `load()` 恢复，旧任务正常展示。

## 4. 关键细节：任务完成 ≠ 学习记录已保存

按补充要求明确分离：

- 保存学习记录只写 `studyLogs`，**不修改任务状态**；
- 任务只有明确“完成”或阶段记录全部完成才进入归档；
- 若任务有已记录的阶段但仍有阶段未完成，点击“完成”会阻止整任务收纳并打开阶段记录；
- 提示语明确：“学习记录已保存；不自动视为任务完成，请在任务上单独确认完成”；
- 因此“课程已听但练习未做”不会因听课时长自动收纳。

## 5. 排序

### 待完成

1. 逾期未完成（date < 今天）
2. 今天
3. 未来

同日期按计划开始时间；无时间按优先级/标题稳定排序。

### 已完成

- 按 `completedAt` 倒序；
- 缺少完成时间的旧任务按原计划日期倒序；
- 归档内再按完成日期分组。

- 历史任务如果既无 `completedAt` 也无 `date`，归档显示“未知日期”。
- 本轮未在真实用户 `%APPDATA%` 上操作；所有测试使用隔离 Profile。
