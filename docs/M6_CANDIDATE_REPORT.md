用户操作详见使用说明.md。先完整备份1.0.1数据，关闭旧版，保持安装范围，再经题库备份门启用v6；旧版不能直接恢复v6备份。检查候选建议使用 scripts/run-isolated.cjs，以新临时Profile运行。
