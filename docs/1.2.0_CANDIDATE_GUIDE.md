## 2. 真实 UI 操作流

### 2.1 学习计划导入

1. 左侧“学习计划” → 导入计划 JSON/CSV。
2. 选择本地文件 → 预览日期、时间、任务类型、阶段和冲突。
3. 确认后只创建/更新计划任务，不会自动把任务标记为完成。

### 2.2 学习记录与 19→18 审计

1. “学习记录” → 选择既有记录“编辑”，或在“详情”查看 revisions。
2. 修改实际完成题数/正确数/内容/用时；保存时校验当前 revision，拒绝覆盖并发旧编辑。
3. 19→18 会保留原 ID；`revision` 递增；保存 before/after 与更正 reason 审计；不是静默改写统计。
4. 删除为软删除，保留审计；历史统计排除已删除记录。

### 2.3 外部成绩与错因

1. “批量导入粉笔外部练习” → 预览来源、externalId、题量、正确数、类型、错因、报告引用。
2. 同一 `source+externalId` 幂等；同 ID 不同内容明确冲突，不静默覆盖。
3. “学习记录”可查看外部错题的主因/次因、方法、逻辑符号、推理和复测历史。
4. 外部记录不修改原 PDF、内部作答或内部 attempt。

### 2.4 7/9 申论评分

1. 编辑或批量导入申论记录，分别填写首次 7/10 和复评 9/10。
2. 两条评分都可追踪；申论不进入客观题正确数/分母，不折算为 9 道题。
3. 结构化复盘可引用申论评分目标，但只作为建议性复盘，不自动覆盖原评分。

### 2.5 复测、归档与趋势

1. “错题本与复测”生成/查看 D+1/D+3/D+7；复测结果按实际完成日期记录。
2. 可提前、推迟、跳过或关闭；每次结果/变更保留，不能凭一次正确自动改写 mastery。
3. 本地 PDF 归档入口：左侧任一学习页（如“学习记录”）→ 顶部“复盘报告”tab（`data-ltab="reports"`）→“＋ 归档复盘 PDF”（`learnImportReport`）；从学习记录可回到归档定位，不移动原 PDF。
4. 行测训练查看长材料连续 PDF；人工修正题号/题型/答案并保留计时。
5. “历史趋势”切换 7/14/30 天，查看模块、用时、错因、首次/重复/未知、复测和申论来源评分；无样本显示“数据不足”。

### 2.6 结构化复盘（WP10）

1. “学习记录”或“学习反馈” → “导入结构化复盘 JSON”。
2. 预览显示来源/批次/hash、活动、复盘、更正、冲突路径和“目标/来源评分记录”；**确认前不写任何数据**。
3. 取消、关闭、源文件变化、目标 revision/hash 变化、恢复/清空/离开都会拒绝或取消旧预览。
4. “确认导入”后只有一个事务成功才提示成功；批次写入 meta、学习记录及真实引用目标审计。
5. “复盘批次”查看状态、payload/hash、活动内容/原始时间、review/correction、目标定位；批次详情和记录“复盘”均提供“查看完整复盘”，完整显示摘要全文、主/次错因、知识点、全部建议、原始 reviewed_at、备注、来源和真实目标（长文本内部滚动，按钮可到达）。
6. 批次详情“撤销本批次”：只撤本批，保留批次/原始 payload/审计；后续编辑、复测、活跃批次引用会整批拒绝；B 已撤销后不再永久锁 A。
7. 学习记录行“复盘”查看关联复盘；建议性内容明确未确认，不自动改原成绩/错因统计。
8. “导出目标上下文/模板”生成本地 JSON：`targetCatalog[]` 为 `{label,target}`，严格 target 只使用 `target`；应用导出模板使用真实 hash。
9. `sourceRef` 不自动打开或上传；所有导入文本按文字 escape，不执行 HTML/脚本。

### 2.7 复盘身份与重导

- 复盘实体身份 = 生产者 namespace + `review_id`；同一 target 的不同 `review_id` 可并存。
- 已撤销批次的 `review_id` 保留为历史；重新复盘必须使用显式新的 `review_id` 创建新实体，不能复活旧实体。
- 活动显式新批次 reimport 与 review_id 新建是两套策略；不能把“任意原文件一键原样重导”作为承诺。

## 4. 已知限制

- 粉笔数据由用户主动提供，不是登录爬取；没有粉笔账号接入。
- 不自动原创题目、不做云同步、不自动上传学习数据。
- 未知/`null` 不猜 0、不猜 new/retest；无标准答案不判错。
- 活动总时长不生成逐题用时分布；只有真实逐题计时进入逐题样本。
- 申论 7/9 保留，不进入客观题正确数/分母。
- 结构化复盘是建议性记录，不自动修改原始 Attempt、错因统计或已确认评分。
- OCR 继续人工核对；自动识别不保证 100% 正确。
- 源码 `templates/review-exchange-v1.template.json` 的零 hash 只是字段示例，不是可提交批次；实际使用应用导出的 targetCatalog/template。
- 1.2 RC 候选不得编造具体 tag/EXE 链接；当前可用性以 [GitHub Releases 列表](https://github.com/GaryZhang12/ExamCard/releases) 为准。
- 本轮未访问真实用户 Profile；应用仍按原路径本地存储。本轮也未替用户执行真实备份，备份/回滚步骤由用户在本机完成。
