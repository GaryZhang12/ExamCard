## 3. EC-CLASS-001 · PDF 大题标题识别一级模块

只实现一级模块，不新增二级知识点、不使用关键词推荐覆盖分类。

### 3.1 模块映射

| 标题示例 | 规范化模块 |
|---|---|
| 第一部分 数量关系 / 数量关系专项练习 | 数量关系 |
| 第二部分 言语理解与表达 / 言语理解 | 言语理解与表达 |
| 第三部分 判断推理 | 判断推理 |
| 第四部分 资料分析 / 资料分析专项练习 | 资料分析 |
| 第五部分 科学推理 | 科学推理 |
| 政治理论专项 | 政治理论 |
| 常识判断 | 常识判断 |
| 深圳特色专项 | 深圳特色专项 |

### 3.2 行为

- 标题后的连续题目继承模块；遇到新标题切换。
- 标题可在上一页、题目在下一页；跨页继承已验证。
- 目录点线/页码、页眉页脚、材料标题、题干文字不会被当作大题标题。
- 页眉小字号重复标题会被过滤；大题标题本身保留。
- 题号在大题内从 1 重新开始时，导入使用全局唯一题号（`n`）并保留 `printedNumber`/原题号，避免同号覆盖或合并。
- 标题无法映射时标 `module-review` / 待确认，不静默塞入上一模块；用户可在预览中修改。
- 用户手工修改 module 后设为 `moduleStatus=manual`，重新渲染不覆盖；确认导入保留。
- 题型识别与模块识别独立。

## 6. EC-QA-001 · 审核状态一致性

- 打开详情：不写数据库。
- 取消：不写数据库。
- 普通保存题干/选项/答案：不自动审核通过；若原题已审核，内容改变后自动退回待审核。
- 仅“审核通过”按钮执行显式审核；先校验题型、题干、选项、答案、冲突、必要材料/图片。
- 无答案、答案冲突、缺少必需图表、题型待确认均不能通过。
- 未审核内容不进入随机组卷/独立练习资格。
- 77 题不会被批量改成审核通过。

证据：`reports/review-state.json`、`tests/review-state-ui.cjs`、`tests/m2-bank.cjs`。
