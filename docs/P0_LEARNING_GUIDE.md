# ExamCard 1.2.0 P0 学习记录操作手册

本手册覆盖本批实际交付：每日计划导入、学习记录编辑/删除/批量新增、粉笔外部练习批量导入、外部错题、申论评分历史和统计查看。WP06–WP10 尚未交付。

> 测试或试用请在 ExamCard 正常桌面会话中使用隔离 Profile；不要指向真实 `%APPDATA%/gd-exam-card-v3`。源码目录的自动化入口会创建 `examcard-work-test-*` 临时 Profile。

## 1. 导入每日学习计划

1. 打开“学习计划”页签。
2. 点击“导入学习计划”，选择 `examcard.daily-plan/v1` JSON（或 CSV）。
3. 在预览中核对：计划日期、考试类别、任务数量、总时长；任务标题、开始/结束时间、学习模式、阶段、课程/教材关联、计划分钟/题数。
4. 预览右侧会显示：
   - `新增`：新任务；
   - `未变化`：同一 `plan_id + task_id` 且计划内容未变；
   - `更新（仅计划字段，保留实际完成）`：计划内容改变；
   - `已完成，跳过更新`：任务已完成，实际完成数据不会被覆盖。
5. 点击“确认导入”。

注意：

- 未在 EC 中建立的题集请使用 `question_set_id: null`，不要编造 ID。
- `priority` 只能是 `high/normal/low`；未知字段、错误枚举会显示字段路径并阻止导入。
- 同一文件重复导入不会产生重复任务。
- 计划导入不会自动把任务标为完成。

## 2. 手动新增学习记录

1. 打开“学习记录”页签。
2. 点击“＋ 手动学习记录”。
3. 填写日期、内容；可选模块/专题/知识点。
4. 题量与正确数：
   - 必须是非负整数；
   - 正确数不能大于题量；
   - 只填正确数不填题量会被拒绝。
5. 用时：
   - **精确**：选择“精确”，可填整数秒（如 235、980）或分钟小数；秒与分钟同时填时必须一致。
   - **估算**：选择“估算”，可填分钟小数，统计会标明估算。
   - **未知**：选择“未知”，时长保存为 `null`，不按 0 计，也不伪装成精确用时。
6. 保存。

## 3. 更正历史记录：19/30 → 18/30

1. 在记录列表中找到原记录（不要新建一条）。
2. 点击“编辑”。
3. 将正确数从 19 改为 18；如需要，填入三组：
   ```json
   [
     { "label": "第一组", "questionCount": 10, "correctCount": 7, "durationSeconds": 235 },
     { "label": "第二组", "questionCount": 10, "correctCount": 6, "durationSeconds": 389 },
     { "label": "第三组", "questionCount": 10, "correctCount": 5, "durationSeconds": 356 }
   ]
   ```
   用时填 980 秒，精度“精确”。
4. **必须填写更正原因**，例如“历史 19/30 更正为 18/30”。
5. 保存。记录 ID 不变，不会新增重复行；统计立即刷新为 18/30、980 秒。
6. 点击“详情 → 修订历史”可查看 before/after 与原因。

如果另一个窗口/编辑已经更新了同一记录，旧页面保存会提示冲突并要求刷新，不会静默覆盖新版本。

## 4. 批量新增手动记录

1. 点击“批量新增记录”。
2. 粘贴 JSON 数组，或 `{ "records": [...] }`：
   ```json
   [
     { "date": "2026-11-02", "content": "资料分析专项", "durationSeconds": 235, "durationPrecision": "exact", "durationUnit": "seconds", "questionCount": 10, "correctCount": 7 },
     { "date": "2026-11-02", "content": "判断推理专项", "durationPrecision": "unknown", "questionCount": 6, "correctCount": 3 }
   ]
   ```
3. 全部记录通过校验后才会在一个事务中写入；任意一行失败则整批零写入，并显示字段路径。

## 5. 批量导入粉笔外部练习

1. 点击“批量导入粉笔外部练习”，选择 JSON 文件。
2. 文件格式（合成示例）：
   ```json
   {
     "schema": "examcard.external-practice-batch/v1",
     "note": "个人记录，可选",
     "records": [
       {
         "source": "fenbi",
         "externalId": "practice-20261102-zl",
         "date": "2026-11-02",
         "assessment": "objective",
         "practiceType": "new",
         "module": "资料分析",
         "topic": "专项练习",
         "knowledgePoint": "增长率",
         "content": "资料分析专项 5/6",
         "questionCount": 6,
         "correctCount": 5,
         "durationSeconds": 300,
         "durationPrecision": "exact",
         "durationUnit": "seconds",
         "reportRef": "粉笔报告/本地文件名",
         "taskId": null,
         "retestStatus": "not_required",
         "wrongQuestions": [
           {
             "questionNo": "4",
             "questionType": "single",
             "knowledgePoint": "增长率",
             "primaryCause": "审题错误",
             "secondaryCauses": ["计算或估算错误"],
             "method": "先定位时间与单位，再列式估算",
             "logicSymbols": "",
             "reasoning": "复盘记录",
             "retestHistory": []
           }
         ]
       }
     ]
   }
   ```
3. 预览会显示新增、内容相同重复、内容冲突、批次内重复、错误数量。
4. 只有“新增”会写入；`source + externalId` 已存在且内容不同时显示冲突并跳过，**不会覆盖**。要更正原记录，请在记录列表编辑原记录并填写原因。
5. 同一批中 `source + externalId` 重复会报错并阻止整批导入。
6. `practiceType` 取值：`new`（专项新题）、`retest`（错题复测）、`comprehensive`（综合练习）、`mock`（模考）。
7. 外部练习不会修改 EC 内部 attempt、试卷或得分记录。

## 6. 外部错题与复测历史

- 每条记录右侧“错题 N”可查看来源、练习 ID、题号、题型、知识点、主/次错因、方法、逻辑符号、推理和复测历史。
- 不同来源或不同练习可以有相同题号，系统使用 `source + externalId + questionNo` 命名空间，不会互相覆盖。
- 复测历史格式：
  ```json
  [
    { "date": "2026-11-03", "status": "passed", "note": "同类题复测", "score": 2, "maxScore": 2 }
  ]
  ```
- 内部题目的 `questionId`、原始 attempt 和复测记录不因外部练习导入而改变。

## 7. 申论评分：首次 7/10 与复评 9/10

1. 新增/编辑记录时把“考核类型”选为“申论评分”。
2. 填写首次得分/满分/备注；如有复评，再填复评得分/满分/备注。
3. 两次评分都保留在同一记录中，详情和统计列表分别显示“首次 7/10”“复评 9/10”。
4. 申论分数不会转成“9 道正确题”，也不会进入客观题专项合计。
5. 如只需先记首次评分，可先保存 7/10；之后编辑追加复评 9/10，修订历史保留旧值。

## 8. 查看统计

“学习记录”页签顶部按以下分类显示：

- 客观练习小计（不含综合/模考）= 新题 + 复测 + 未分类：真实报告派生为 30/48、错 18、62.5%；未分类题数明确显示，不猜成新题/复测；
- “专项新题”卡片只表示明确 `new` 标签，不等于全部专项；全 new 合成用例仍是有效的 30/48 算法样本；
- 综合练习 11/15（真实报告）或 15 题正确未知（合成反例）单列，不并入小计；
- 错题复测、模考分别累计；
- 外部活动总数、正确未知项数、外部错题数；
- 申论评分列表，首次与复评均在。

规则：

- 未知正确数不按 0 计；有未知正确数时合计正确率显示“—”。
- 未知用时显示“用时未知”，不显示 0 分钟。
- 同一外部练习 `source + externalId` 只计一次。
- 带 `taskId` 的外部活动与对应已完成任务不会重复计入任务实际汇总。

## 9. 删除记录

1. 点击“删除”。
2. 必须填写删除原因并确认。
3. 删除为软删除：记录从列表/统计隐藏，但保留 `status=deleted`、删除时间、原因和 before/after 审计；不会物理删除历史。
4. 备份/恢复会保留软删除行及其审计。

## 10. 备份与恢复

1. 主页“数据安全 → 导出完整备份”生成覆盖全部 28 张表（v6）的 JSON。
2. 恢复前会校验格式、表数量、记录数、记录 SHA-256 和整体 SHA-256；失败不会覆盖当前数据。
3. 恢复是整库覆盖；恢复前先导出当前备份。
4. P0 不新增表，`studyLogs` 新字段随原表备份/恢复，无需额外迁移。
