# ExamCard 1.2.0 P1 操作手册（WP06–WP08）

本手册仅覆盖本轮 P1；P2（趋势、批量复盘交换）尚未实现。

## 1. 生成 D+1/D+3/D+7 复测

1. 在“学习记录”中保存真实错题（外部错题需有来源、外部练习 ID、题号；内部题保留题号/题目 ID）。
2. 打开“学习计划”页签。
3. 点击“生成 D+1/D+3/D+7 复测”。
4. 系统按错误日期生成三条待办：
   - 2026-11-02 错误 → 11/3、11/5、11/9；
   - 内部错题有 `lastWrongAt` 原始时间戳时按北京日期转换（例如 UTC 11/2 16:00 = 北京 11/3，计划为 11/4、11/6、11/10），不采用主机本地日期；
   - 只有无时间戳的旧数据才沿用显式错误日期，并在“复测历史”注明“无时间戳，兼容显式错误日期”；外部练习的显式 date 不转换；
   - 任务状态为“待完成”，不会因生成计划自动完成；
   - 每项标记“原题复测 / D+1/3/7”，并保存原始错误、错因、方法、逻辑符号、推理。
5. 再次点击只跳过已存在项，不重复生成。
6. 同一题在另一个日期再次做错时，会产生独立的新周期，不覆盖旧周期历史。

## 2. 提前、推迟、跳过、关闭提醒

1. 在“今日背诵 / 到期复测”或“全部任务”中找到复测项。
2. 点击：
   - “提前”：选择新的较早日期；
   - “推迟”：选择新的较晚日期；
   - “跳过”：只把本次提醒标为已跳过；
   - “关闭提醒”：关闭该项提醒；
   - “同类新题”：创建一个独立的同类新题验证任务，不修改原题复测。
3. 填写原因并保存。
4. 所有动作追加到“复测历史”，不会删除原错误或已有成绩。
5. 跳过/关闭的任务仍在任务表保留，可查看历史，但不进入到期提醒。

## 3. 记录每次复测成绩

1. 到期后打开复测任务，点击“完成”。
2. 填写实际完成日期、实际题数、正确数、分钟；这些是用户确认的实际值。
   - 日期默认是今天（Asia/Shanghai）；补录过去日期可直接改；
   - 不允许填写未来日期，系统不会用计划日补造未来成绩。
3. 完成后：
   - 任务进入已完成归档；
   - `每次复测成绩` 追加一条（实际完成日期、计划截止、原始错误日期、原题/同类、正确/题量、评分、备注）；
   - 掌握状态保持“待继续验证”，一次正确**不会**自动标记完全掌握；
   - 计划完成与成绩记录分别保存，原任务 `date/dueDate` 不被成绩改写。
4. 点击“复测历史”查看原始错误、日期变更、跳过/关闭和每次成绩。

## 4. 归档学习复盘 PDF

1. 打开“学习/复盘报告”页签。
2. 点击“归档复盘 PDF”，选择本机 PDF。
3. 预览文件大小/SHA-256；PDF 必须能被内置 PDF.js 真正打开（只有 `%PDF` 标头的坏文件会被拒绝，且不写入）。填写：
   - 标题；
   - 日期（YYYY-MM-DD）；
   - 专题、关键词、知识点（逗号分隔）；
   - 备注（可选）。
4. 点击“保存归档”。
5. EC 保存独立 PDF 副本和元数据；原文件不被移动、覆盖或删除。
6. 取消文件选择/取消元数据弹窗、关闭/切换学习界面不会写入任何数据；读取中执行恢复或清空也会取消迟到的归档回写。
7. 在列表中可按日期、标题、专题、关键词、知识点检索；“打开归档”使用 PDF.js 实际渲染，支持上一页/下一页。
8. 删除归档只删除 EC 副本与索引，不删除原始 PDF。

## 5. 从学习记录打开复盘报告

1. 在“学习记录”列表找到记录。
2. 点击“复盘报告”。
3. 若该日期有 1 份归档，直接打开 PDF；多份则显示按日期筛选的列表；没有则明确提示“该日期没有归档复盘报告”。
4. 归档缺失/Blob 断链会提示重新归档，不删除学习记录。

## 6. 连续滚动阅读

1. 进入试卷答题页，PDF 工具栏点击“连续滚动”。
2. 页面在同一个滚动容器中连续排列；向下滚动即可看到相邻页。
3. 只会按需渲染当前页附近页面；远离当前页的 canvas 会释放，避免整本预渲染占内存。
4. 页码输入、上一页/下一页、定位当前题在连续模式仍有效。
5. 缩放/适应宽度会重建连续页块，保留当前页与答案/计时。
6. 再次点击“单页模式”回到原单页阅读；当前页、答案、标记、计时不丢失。
7. 修正定位可在连续页块上直接单击题目实际位置。

## 7. 备份与恢复

- 复盘报告索引和 PDF Blob 存在既有 `meta` 表；旧 v5/22 与 v6/28 完整备份都会包含它们。
- 恢复完整备份会恢复报告资源和索引；不要用“恢复”代替普通追加导入。
- 复测任务在既有 `learningTasks` 表；备份恢复同样保留。
- 恢复前先导出当前完整备份；恢复失败不会覆盖当前数据。

## 8. 已知限制

- P2 的趋势统计和批量复盘交换尚未实现。
- 归档检索基于元数据，不对 PDF 全文做 OCR。
- 连续模式首版无缩略图侧栏/文字选择；复杂图表仍以 PDF.js 原页渲染为准。
- 真实报告仅通过本机文件选择使用，不进入源码/发布包。
